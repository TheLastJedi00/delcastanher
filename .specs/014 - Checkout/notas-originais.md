# Informações de projeto mercado Pago
- Checkout Transparente
- API de Pagamentos
- Nome da aplicação: Delcastanher
- Nota fiscal de Produto físico
# O que é pago?
- A compra de apenas um módulo
- Ou mais de um (O cliente seleciona os módulos que quer)
- Acesso por 6 meses pra qualquer módulo comprado a partir da data de compra
# Quando é pago?
- Após onboarding,tela de loja de módulos
- Processo obrigatório por guards
- Se não comprar o acesso do usuário é salvo mas sempre volta na loja de módulos
- Na loja ele Ainda tem acesso ao prórprio perfil pra editar próprios dados
