# Caso comando: Formatar
- reescreva o context .md de toda a spec pra que se mantenha o mesmo porém escrito seguindo a linguagem markdown
# Caso comando: Taks
- leia todo o context.md-
- seguido a melhores diretrizes da stack atual para atingir todo o objetivo necessário para finalizar essa spec
- Escreva um arquivo chamado de tasks.md na mesma pasta da spec com a lista de todas as fases sendo as fases divididas em tasks
# Caso comando: Executar
- comece a executar as fases sendo uma branch feat/<> por fase e um commit por task dessa fase
- ao fim das fases faça o merge das feats em uma branch release/<nome-da-spec>
- suba a branch em localhost 4200 caso front e 300 caso backend
